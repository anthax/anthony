# NORTHSTAR ADVISORY

### Project Brief & Development Guide

**Project Type:** Premium B2B Consultancy Website
**Project Status:** Initial Setup
**Development Approach:** Project-Based Learning
**Technology Stack:** HTML5, CSS3, Vanilla JavaScript

---

## 1. Project Overview

Northstar Advisory is a fictional premium business strategy and management consultancy.

The company helps ambitious businesses improve their operations, develop effective strategies, solve organisational challenges and achieve sustainable growth.

The objective is to build a sophisticated, modern, responsive business website that communicates professionalism, credibility and strategic expertise.

This project will also serve as a practical frontend development environment for learning and implementing HTML, CSS and JavaScript.

## 2. Project Objectives

- Build a professional, client-quality business website.
- Develop practical frontend development skills.
- Learn JavaScript through real website features.
- Practise responsive web design.
- Understand how different frontend technologies work together.
- Develop the ability to build websites independently.
- Create a strong portfolio demonstration project.

## 3. Visual Identity: Northstar Glass

The website will adopt a premium liquid-glass aesthetic inspired by modern glassmorphism interfaces.

### Design Philosophy

**70% Premium Minimalism + 30% Liquid Glass**

The design should feel futuristic, sophisticated and professional without becoming visually overwhelming.

## 4. Website Structure

The website will be a single-page business website containing the following sections:

1. **Navigation:** Brand identity, navigation links and consultation CTA.
2. **Hero:** Main headline, company introduction and primary CTA.
3. **About:** Company overview, philosophy and positioning.
4. **Services:** Strategy, operations and technology consulting.
5. **Our Process:** How Northstar works with clients.
6. **Case Studies:** Selected business projects and outcomes.
7. **Testimonials:** Client feedback and experiences.
8. **FAQ:** Frequently asked questions.
9. **Contact:** Enquiry form and consultation information.
10. **Footer:** Contact details, navigation and social links.

## 9. Learning Methodology

This project follows a learn-by-building approach.

For every feature:

1. Identify the feature to implement.
2. Identify the concepts required.
3. Learn unfamiliar concepts before implementation.
4. Build the feature through guided exercises.
5. Debug and review the implementation.
6. Improve the feature and understand why the code works.

### Learning Rules

- Do not provide complete solutions immediately when an exercise can be solved independently.
- Give hints and explanations before revealing full solutions.
- Explain unfamiliar JavaScript concepts clearly.
- Encourage independent problem-solving.
- Avoid unnecessary tutorials and isolated exercises.
- Apply every relevant concept to the actual project.
- Do not introduce React before establishing strong vanilla JavaScript foundations.

## 10. Quality Standards

The finished website should:

- Work across desktop, tablet and mobile.
- Have consistent visual styling.
- Use semantic and accessible HTML.
- Have organised, maintainable CSS and JavaScript.
- Include functional interactive components.
- Avoid unnecessary visual clutter.
- Have sensible fallbacks for unsupported CSS features.
- Respect reduced-motion preferences.
- Use realistic, clearly identified fictional company information and project examples.
- Avoid presenting fabricated testimonials or business statistics as genuine results.

## 11. Definition of Completion

Northstar Advisory is considered complete when:

- All planned website sections are implemented.
- All 12 required JavaScript features are functional.
- Responsive behaviour has been tested.
- Forms have appropriate validation and submission handling.
- The visual identity is consistent.
- The code is organised and maintainable.
- The website is deployed and ready for portfolio presentation.
